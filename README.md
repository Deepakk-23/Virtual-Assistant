# 🤖 Virtual Assistant

A modern full-stack AI-powered Virtual Assistant web application built using the MERN stack.  
This project includes authentication, voice assistant functionality, real-time AI interaction, and a responsive user interface.

---

## 🚀 Features

- 🎤 Voice Assistant Support
- 🔐 User Authentication & Authorization
- 💬 Real-Time AI Chat
- ⚡ Fast & Responsive UI
- 🌐 Full Stack MERN Application
- 🔒 Secure Backend APIs
- 📱 Mobile Responsive Design
- 🧠 AI-Powered Responses
- 🔄 Real-Time Communication

---

# ⚙️ Installation & Setup

## 1️⃣ Clone Repository

```bash
git clone https://github.com/Deepakk-23/Virtual-Assistant.git
```

---

## 2️⃣ Navigate to Project Folder

```bash
cd Virtual-Assistant
```

---

# 🔧 Backend Setup

## Install Backend Dependencies

```bash
cd backend
npm install
```

## Start Backend Server

```bash
npm run dev
```

Backend will run on:

```bash
http://localhost:5000
```

---

# 💻 Frontend Setup

## Open New Terminal

```bash
cd frontend
npm install
```

## Start Frontend

```bash
npm run dev
```

Frontend will run on:

```bash
http://localhost:5173
```

---

# 🔑 Environment Variables

Create a `.env` file inside the `backend` folder and add:

```env
PORT=5000
MONGODB_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
GEMINI_API_KEY=your_gemini_api_key
```
